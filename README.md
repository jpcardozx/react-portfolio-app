# 🎯 React Portfolio App

A **modern, high-performance portfolio website** built with [React](https://reactjs.org/) and [Vite](https://vitejs.dev/), designed for developers and digital professionals who want to stand out with style and substance.

This project offers a clean architecture, blazing-fast build times, and fully customizable sections — all with a focus on simplicity and scalability.

> 🔗 **Live Preview**: [https://jpcardozx.github.io/react-portfolio-app/](https://jpcardozx.github.io/react-portfolio-app/)

---

## ⚡️ Features

- ✅ **Single Page Application (SPA)** with smooth transitions
- ✅ **Modular component structure** for easy customization
- ✅ **Responsive design** – mobile-first, pixel-perfect
- ✅ **Blazing fast dev experience** with Vite
- ✅ **SEO-friendly** and deployable via GitHub Pages or Vercel

---

## 🧠 Tech Stack

| Tool             | Purpose                         |
| ---------------- | ------------------------------- |
| **React**        | UI Library                      |
| **Vite**         | Lightning-fast bundler          |
| **React Router** | Client-side routing             |
| **gh-pages**     | GitHub Pages deployment         |
| **Vercel**       | Optional alternative deployment |

---

## 🚀 Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/jpcardozx/react-portfolio-app.git
cd react-portfolio-app
npm install
npm run dev
```
